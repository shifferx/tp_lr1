# Лабораторная работа №1 — Сбор информации об операционной системе

## Описание

Скрипт предназначен для определения текущей операционной системы и сбора информации о компьютере, на котором он запущен.

Программа является кроссплатформенной и предназначена для работы в Windows, Linux и macOS.

После запуска скрипт собирает информацию об операционной системе и аппаратных ресурсах компьютера, после чего сохраняет полученные данные в файл `system_info.json` в формате JSON.

Для получения информации не используются системные утилиты ОС.

## Собираемые параметры

### Система

Скрипт собирает следующие сведения о системе:

- имя компьютера (`hostname`);
- полное доменное имя (`fqdn`);
- название операционной системы;
- релиз операционной системы;
- версия операционной системы;
- полное описание платформы;
- архитектура компьютера;
- информация о процессоре;
- время загрузки системы;
- время работы системы с момента загрузки;
- информация о пользователях, вошедших в систему:
  - имя пользователя;
  - терминал;
  - хост;
  - время начала пользовательской сессии.

### Python

Собирается информация о среде Python:

- версия Python;
- используемая реализация Python.

### Процессор

Для процессора собираются:

- количество физических ядер;
- количество логических ядер;
- текущая частота процессора;
- минимальная частота;
- максимальная частота;
- общая загрузка процессора в процентах;
- загрузка каждого логического ядра в процентах.

### Оперативная память

Для оперативной памяти собираются:

- общий объём;
- доступный объём;
- используемый объём;
- свободный объём;
- процент использования памяти.

Размеры памяти сохраняются как в байтах, так и в удобном для чтения формате: B, KB, MB, GB, TB или PB.

### Swap-память

Собираются:

- общий объём swap-памяти;
- используемый объём;
- свободный объём;
- процент использования.

Объёмы также представлены в байтах и в удобном для чтения формате.

### Диски и разделы

Для доступных разделов дисков собираются:

- имя устройства;
- точка монтирования;
- тип файловой системы;
- параметры монтирования;
- общий объём;
- занятый объём;
- свободный объём;
- процент использования.

Размеры дискового пространства сохраняются как в байтах, так и в удобном для чтения формате.

## Используемые модули

В программе используются стандартные модули Python:

- `json` — формирование и сохранение данных в формате JSON;
- `pathlib` — работа с путём к выходному файлу;
- `platform` — получение информации об операционной системе, архитектуре и Python;
- `socket` — получение имени компьютера и FQDN;
- `datetime` — работа с датой и временем.

Также используется внешний модуль:

- `psutil` — получение информации о процессоре, оперативной памяти, swap-памяти, дисках, времени загрузки системы и пользовательских сессиях.

### Почему используется psutil

Стандартная библиотека Python позволяет получить основную информацию об операционной системе с помощью модуля `platform`, однако она не предоставляет единого кроссплатформенного интерфейса для получения подробной информации о загрузке процессора, оперативной памяти, swap-памяти и использовании дисковых разделов.

Модуль `psutil` предоставляет единый Python API для Windows, Linux и macOS, благодаря чему одну реализацию программы можно использовать на разных операционных системах без запуска сторонних системных утилит и разбора их вывода.

Поэтому `psutil` используется для получения тех системных параметров, для которых возможностей стандартной библиотеки Python недостаточно.

## Установка

Для работы программы необходим Python 3.

Перед запуском необходимо установить модуль `psutil`:

```bash
python -m pip install psutil
```

Остальные используемые модули входят в стандартную библиотеку Python и дополнительной установки не требуют.

## Запуск

Скрипт запускается из командной строки:

```bash
python my_script.py
```

где `my_script.py` — имя файла со скриптом.

После выполнения программы в текущей директории создаётся файл:

```text
system_info.json
```

В консоли также выводится полный путь к созданному файлу.

## Результат работы

Результат сохраняется в формате JSON и имеет следующую общую структуру:

```json
{
    "system": {
        "...": "..."
    },
    "cpu": {
        "...": "..."
    },
    "memory": {
        "...": "..."
    },
    "disk": {
        "...": "..."
    }
}
```

Таким образом, программа автоматически определяет характеристики текущей системы, собирает набор системных параметров и сохраняет полученную информацию в структурированном JSON-файле.
